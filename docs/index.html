A bodycam inside Minecraft.

NEXUS Bodycam is a 100% client-side rework of the first-person camera. It changes how the camera looks and feels — never movement speed, hitboxes, raycasts or server logic.

Footsteps are also surface-aware: sound and shake change with the block underfoot (grass, sand, stone, water).

It never touches raycasts, bullets or aiming. Without TACZ installed the mixins disable themselves via BodycamMixinPlugin.

Genuinely optional

TACZ is not a dependency — it is a bonus. The mod compiles, installs and runs on a machine that has never seen a TACZ jar. Two things guarantee that, and both are about compilation, not runtime:

PieceWithout the TACZ jar
TaczBridge Compiles. It has no import com.tacz.* at all — it resolves the API via reflection.
TaczGunTransformMixin Left out. It must @Mixin a TACZ class, so there is no way to compile it.
No third-party code enters the repository. The TACZ jar is gitignored, none of its code is copied, and none of its classes are bundled into the final jar — build.gradle only consumes it as modCompileOnly.

How the reflection works

Two details make this cheap and hard to break:

  • TACZ's event bus is the Fabric event bus (net.fabricmc.fabric.api.event.Event), which you already depend on. Only the listener type becomes a proxy — registration is an ordinary call.
  • Minecraft types are never named. The live ClientPlayerEntity is handed straight to the reflective call, so the code is tied to no mapping.
  • Lookups match by name + arity, not by descriptor. If TACZ ever renames a method the bridge disables itself with a log — never a LinkageError.

What TACZ adds

  • Weapon spring of 2nd order with overshoot — recoil has weight.
  • Weapon lower while sprinting and while crawling.
  • Run sway plus stabilization while aiming (ADS).
  • Reload response and wall proximity.
  • Phase D kit: inertia, movement-to-aim, recoil kick.
Architecture

The contract: pure client-side

The mod changes only how the camera is drawn. No competitive advantage — by construction, not by promise.

What it does

  • Rewrites the world render matrix
  • Adds post-processing shaders
  • Plays local breathing audio
  • Saves config to config/bodycam.json

What it does NOT do

  • No change to speed or collision
  • No touching of hitboxes or raycasts
  • Nothing is sent to the server
  • No effect on TACZ bullets or aiming

Injection points

  • CameraMixin — camera rotation
  • GameRendererMixin — render phase
  • EntityMixin — footsteps ↔ audio
  • TaczGunTransformMixin — weapon (TACZ only)

Installation

Three steps

Requirements: Fabric Loader ≥ 0.15.11 · Fabric API · Java 17+.

Install Fabric Loader

For Minecraft 1.20.1. Get it from the official site.

Download the JAR

Grab NEXUS-bodycam-1.4.3+1.20.1.jar from the latest release — that link goes straight to the file.

Drop it in mods/

Optional: Mod Menu for the config screen, TaCZ for guns, Iris for shaders.

Building from source

git clone https://github.com/jhfuheuiwfh/nexus-bodycam-mod.git
cd nexus-bodycam-mod
./gradlew build          # Windows: gradlew.bat build

The artifact lands in build/libs/. It compiles without TACZ — in that case the weapon mixin is left out and the bridge stays off. For the full package, put the TACZ jar in libs/ before building. libs/ is gitignored because that jar is third-party.
