Uma câmera de bodycam
dentro do Minecraft.

NEXUS Bodycam é uma reformulação 100% client-side da câmera de primeira pessoa. Ele muda como a câmera parece e se sente — nunca velocidade de movimento, hitboxes, raycasts ou lógica de servidor.

Passos também são surface-aware: o som e o tremor mudam conforme o bloco sob o pé (grama, areia, pedra, água).

Nunca toca em raycasts, balas ou mira. Sem o TACZ instalado os mixins se desabilitam sozinhos via BodycamMixinPlugin.

Opcional de verdade

O TACZ não é uma dependência — é um bônus. O mod compila, instala e roda em uma máquina que nunca viu um jar do TACZ. Duas coisas garantem isso, e as duas são sobre compilação, não sobre runtime:

PeçaSem o jar do TACZ
TaczBridge Compila. Não tem nenhum import com.tacz.* — resolve a API por reflection.
TaczGunTransformMixin Fica de fora. Precisa @Mixin numa classe do TACZ, então não há como compilá-lo.
Nada de terceiro entra no repositório. O jar do TACZ é ignorado pelo git, nenhum código dele é copiado, e nenhuma classe dele é embutida no jar final — o build.gradle só o usa como modCompileOnly.

Como a reflection funciona

Dois detalhes tornam isso barato e à prova de quebra:

  • O bus de eventos do TACZ é o bus do Fabric (net.fabricmc.fabric.api.event.Event), que já é dependência sua. Só o tipo do listener vira proxy — o registro é uma chamada normal.
  • Tipos do Minecraft nunca são nomeados. O ClientPlayerEntity vivo é passado direto pra chamada reflexiva, então o código não amarra a nenhum mapeamento.
  • A busca é por nome + aridade, não por descritor. Se o TACZ renomear um método, a ponte desliga sozinha com um log — nunca um LinkageError.

O que o TACZ adiciona

  • Mola da arma de 2ª ordem, com overshoot — o recoil "pesa".
  • Baixar arma ao correr e ao andar agachado.
  • Balanço ao correr e estabilização durante a mira (ADS).
  • Resposta a recarga e proximidade de parede.
  • Kit de phase D: inércia, movement-to-aim, recoil kick.
Arquitetura

O contrato: client-side puro

O mod altera apenas como a câmera é desenhada. Nada de vantagem competitiva — por construção, não por promessa.

O que ele faz

  • Reescreve a matriz de renderização do mundo
  • Adiciona shaders de pós-processamento
  • Toca sons de respiração locais
  • Salva config em config/bodycam.json

O que ele NÃO faz

  • Não altera velocidade ou colisão
  • Não mexe em hitboxes nem raycasts
  • Não envia nada ao servidor
  • Não afeta balas ou mira do TACZ

Pontos de injeção

  • CameraMixin — rotação da câmera
  • GameRendererMixin — fase de render
  • EntityMixin — passos ↔ áudio
  • TaczGunTransformMixin — arma (só com TACZ)

Instalação

Três passos

Requisitos: Fabric Loader ≥ 0.15.11 · Fabric API · Java 17+.

Instale o Fabric Loader

Para Minecraft 1.20.1. Baixe no site oficial.

Baixe o JAR da release

Pegue NEXUS-bodycam-1.4.3+1.20.1.jar na release mais recente.

Solte na pasta mods/

Opcional: Mod Menu para a tela de config, TaCZ para armas,

Compilar a partir do código

git clone https://github.com/jhfuheuiwfh/nexus-bodycam-mod.git
cd nexus-bodycam-mod
./gradlew build          # Windows: gradlew.bat build

O artefato fica em build/libs/. Compila sem o TACZ — nesse caso o mixin da arma fica de fora e a ponte fica desligada. Para o pacote completo, coloque o jar do TACZ em libs/ antes de buildar. O libs/ é ignorado pelo git porque esse jar é de terceiros.
